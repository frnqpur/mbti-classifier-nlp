# Recruiter View — MBTI Classifier

## One-Line Pitch
An educational NLP text classification project that predicts MBTI-style personality traits from user-provided text using preprocessing, bag-of-words features, and Naive Bayes classifiers.

## Why This Project Matters
This project is useful as a beginner-friendly machine learning portfolio project because it shows an end-to-end workflow:

- dataset understanding,
- text cleaning,
- feature extraction,
- model training,
- evaluation,
- interactive demo creation,
- responsible explanation of limitations.

## Recruiter-Friendly Summary
MBTI Classifier is a Python-based NLP project that explores whether user-written text can be classified into MBTI-style personality categories. The project applies text preprocessing, converts text into simple word-based features, trains Naive Bayes classifiers, and presents the result through a Streamlit demo.

The project is presented as an educational machine learning baseline rather than a psychological assessment tool.
