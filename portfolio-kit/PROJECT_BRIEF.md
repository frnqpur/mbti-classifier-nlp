# Project Brief — MBTI Classifier

## Project Name
MBTI Classifier — Educational NLP Text Classification Demo

## Short Description
MBTI Classifier adalah project Natural Language Processing (NLP) sederhana untuk mengeksplorasi klasifikasi tipe MBTI berdasarkan teks. Project ini menggunakan text preprocessing, bag-of-words features, dan Naive Bayes classifier sebagai baseline machine learning model.

Project ini diposisikan sebagai **educational classifier**, bukan alat psikologi resmi.

## Main Objective
Tujuan utama project ini adalah menunjukkan workflow machine learning dasar:

1. Membaca dataset teks.
2. Membersihkan dan memproses teks.
3. Mengubah teks menjadi fitur numerik sederhana.
4. Melatih model klasifikasi.
5. Mengevaluasi hasil model.
6. Menyediakan demo interaktif sederhana menggunakan Streamlit.

## Problem Statement
Teks yang ditulis seseorang dapat mengandung pola bahasa tertentu. Project ini mencoba mengeksplorasi apakah pola tersebut dapat digunakan oleh model baseline untuk memprediksi komponen MBTI.

Namun, hasil model tidak boleh dianggap sebagai asesmen psikologis resmi karena MBTI prediction dari teks memiliki banyak keterbatasan, termasuk bias dataset, konteks bahasa, kualitas teks input, dan keterbatasan model sederhana.

## Source-Based Scope
Berdasarkan project asli, pendekatan yang sesuai adalah:

- Python
- NLP preprocessing
- tokenization / word cleaning
- stopword removal
- punctuation removal
- bag-of-words style features
- Naive Bayes classifier
- classification evaluation
- optional Streamlit demo
