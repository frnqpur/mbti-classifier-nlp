# Screenshot and Video Checklist

## Purpose
Use this checklist to prepare clean visual assets for CV, GitHub, LinkedIn, or website portfolio.

## Screenshot Checklist

### 1. Project Repository
File name:

```text
01-github-repository.png
```

Capture:
- repository name,
- clean folder structure,
- README visible.

### 2. Streamlit Landing Page
File name:

```text
02-streamlit-home.png
```

Capture:
- app title,
- short description,
- disclaimer visible.

### 3. Text Input Section
File name:

```text
03-text-input.png
```

Capture:
- text area,
- sample anonymous input,
- predict button.

### 4. Preprocessing Explanation
File name:

```text
04-preprocessing-info.png
```

Capture:
- explanation of cleaned text,
- token / word feature explanation if shown.

### 5. Prediction Result
File name:

```text
05-prediction-result.png
```

Capture:
- predicted MBTI,
- trait-level result,
- confidence if available.

### 6. Disclaimer
File name:

```text
06-disclaimer.png
```

Capture:
- statement that the app is educational,
- statement that result is not psychological assessment.

### 7. README Documentation
File name:

```text
07-readme-documentation.png
```

Capture:
- project overview,
- tech stack,
- limitation section.

### 8. Case Study Page
File name:

```text
08-case-study.png
```

Capture:
- problem statement,
- method,
- result,
- limitation.

## Video Demo Checklist

Recommended duration:

```text
60–90 seconds
```

Suggested flow:

1. Open portfolio page.
2. Show project title and short explanation.
3. Open Streamlit demo.
4. Enter anonymous sample text.
5. Click prediction button.
6. Show predicted MBTI-style output.
7. Show confidence.
8. Show disclaimer.
9. End with project limitations and future improvements.

## Important Privacy Rules
Do not record:

- raw dataset posts,
- personal text files,
- names,
- emails,
- private writing samples,
- full notebook cells containing personal data.

Use anonymous sample text only.
