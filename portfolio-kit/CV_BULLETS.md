# CV Bullets — MBTI Classifier

## English CV Bullets

### Short Version
- Built an educational NLP text classification demo using Python, text preprocessing, bag-of-words features, and Naive Bayes classifiers to predict MBTI-style traits from user input.

### Medium Version
- Developed an educational MBTI-style text classifier using Python, NLP preprocessing, bag-of-words feature extraction, and Naive Bayes models, then converted the workflow into a simple Streamlit demo for recruiter-friendly interaction.

### Strong Version
- Built and documented an end-to-end NLP classification project that preprocesses text, extracts word-based features, trains Naive Bayes classifiers, evaluates model limitations, and deploys a Streamlit demo with responsible educational disclaimers.

## LinkedIn Project Description
Built an educational NLP classifier that predicts MBTI-style traits from user-written text. The project uses text preprocessing, bag-of-words feature extraction, and Naive Bayes classifiers, then presents the workflow through a simple Streamlit demo. This project is positioned as a learning-focused machine learning baseline, not as an official psychological assessment tool.
